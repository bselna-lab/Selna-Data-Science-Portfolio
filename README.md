# Selna-Data-Science-Portfolio
## This repository collects my coding and data projects from Introduction to Data Science.

## Projects:

### 1. [Basic Streamlit App](basic_streamlit_app/)
Through this project, I used a dataset about NBA player statistics to make a basic Streamlit app. This app lets you explore, and you can compare 2 NBA players' statistics. You can then pick a team, then a player from that team, and use the slider feature to zero in on one specific year to compare. Finally, you can view the results in the table and charts that are displayed. 


### 2. [Tidy Data Project: Mutant Moneyball](TidyData-Project/)
Through this project, I cleaned and explored a messy dataset of X-Men comic collection values. I reshaped the data from wide to long format with 'melt()', split combined column names with 'str.split()', cleaned dollar-formatted text into numbers, and handled missing values. I then summarized the tidy data with pivot tables, bar charts, and box plots. The main finding is that collection values fall steeply from the 1960s to the 1990s in every valuation source.

## How These Projects Fit Together
My first project, the Streamlit app, shows that I can build an interactive tool that people can use and explore. The Tidy Data project covers the step that comes before any app or analysis, getting messy data into a tidy shape that is more easily used and trusted. Together, they show both ends of a data workflow: preparing data and presenting it.
